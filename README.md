# Jagruthi Agro Chemicals — Interactive Crop Protection Lab

A static, Vercel-friendly interactive catalogue built from the supplied 12-page Jagruthi Agro Chemicals brochure.

## Run locally

Open `index.html` directly, or use any static server:

```bash
npx serve .
```

## Deploy to Vercel

1. Put this folder in a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other** (or leave Vercel to detect a static site).
4. Build command: leave empty.
5. Output directory: `.`
6. Deploy.

No database or environment variables are required.

## Important source note
The product names/categories are derived from the supplied brochure pages. The site intentionally does not invent dosage, crop-specific recommendations, or safety instructions that are not provided in the brochure.
